## Multi-planet, multi-system, multi-galaxy (long-term vision)

Earth is the shared starting planet for all players, modeled
semi-realistically per [world.md](world.md). Once space exploration unlocks
(see [eras.md](eras.md)), players can build spacecraft and travel to other
planets, which are procedurally generated (not hand-crafted like Earth) and
have discoverable rarity tiers (common → legendary, richer in
resources/features). Players can eventually claim a planet as a second home
base — primitive by default, upgradable only by importing technology via
space logistics. This is a far-future layer built on top of a working
single-planet game; not MVP.
