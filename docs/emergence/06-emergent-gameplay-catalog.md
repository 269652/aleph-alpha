# Emergent Gameplay Catalog

The intended content model is that simulation pressures become gameplay interfaces. Do not build separate content generators when a causal substrate can produce the same result.

## Core cascades

### Economic
```text
resource disruption → scarcity → price change → household stress → migration/crime/politics → institutional response
```

### Ecological
```text
population change → predator/prey change → vegetation change → resource change → settlement consequences
```

### Institutional
```text
repeated cooperation → shared identity → resource pooling → institution → leadership → external goals
```

### Political
```text
competing interests → negotiation → failed negotiation → sanctions → unrest → coercion/conflict
```

### Road to city
```text
resource node → repeated travel → trail → infrastructure → market → settlement → specialization → city
```

### City collapse
```text
dependency failure → shortage → unemployment → migration → infrastructure decay → institutional collapse → abandonment
```

### Dungeon
```text
historical event → physical persistence → ecological/social occupation → hazard/resource concentration → dungeon
```

### Legend
```text
important event → emotional memory → repeated retelling → bounded distortion → cultural narrative
```

### Player mythology
```text
player intervention → persistent consequence → witness memory → institutional record → descendants → legend
```

### Technology diffusion
```text
local innovation → apprentice/merchant/migrant transmission → adaptation → regional specialization
```

### Crime
```text
valuable goods + weak enforcement + unmet needs → crime → repeated cooperation → organized crime
```

### Religion
```text
unusual event + shared interpretation + ritual + repetition → belief community → institution
```

### Boss ecosystem
```text
exceptional organism → territory → prey pressure → migration → rumors → economic response → player intervention
```

## Novel mechanics to prototype

1. **Obligation chains** — broken promises propagate through relationships.
2. **Dependency maps** — settlements expose critical resource and infrastructure dependencies.
3. **Historical counterfactual tools** — developers can test alternative outcomes without mutating production state.
4. **Cultural drift** — stories and rituals mutate across generations.
5. **Institutional schism** — organizations split when goals diverge.
6. **Institutional merger** — organizations merge when cooperation becomes more valuable.
7. **Resource monopolies** — control of scarce resources creates power.
8. **Migration waves** — shocks create correlated movement.
9. **Settlement succession** — abandoned places can be reclaimed while retaining physical history.
10. **Player-founded institutions** — players can deliberately accelerate the same formation mechanism used by NPCs.

## Quest taxonomy

Quest presentation should classify simulation pressures: shortage, danger, dispute, missing person, debt, broken contract, infrastructure failure, migration, ecological imbalance, political conflict, historical mystery, and institutional request.

The quest is an interface to world state, not the world state itself.
