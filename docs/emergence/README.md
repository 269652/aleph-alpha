# Aleph-Alfa Emergent Systems Specification

This directory defines the approved emergent-world substrate for Aleph-Alfa.

## Reading order

1. `00-emergence-architecture.md` — overall architecture and invariants.
2. `01-society-and-institutions.md` — households, relationships, institutions, governance.
3. `02-history-memory-rumors.md` — event graph, memory, beliefs, rumors, legends, archaeology.
4. `03-contracts-property-economy.md` — property, production, contracts, debt, markets, trade.
5. `04-settlements-cities-infrastructure.md` — settlement growth, infrastructure, cities, dependencies.
6. `05-dungeons-bosses-exploration-content.md` — causal dungeons, bosses, ruins, exploration.

8. `07-implementation-roadmap.md` — dependency-ordered implementation plan.
9. `08-claude-code-master-brief.md` — direct execution brief for Claude Code.

## Core philosophy

Persistent content should be a consequence of simulation state. Story, quests, dungeons, cities, factions, bosses, legends, and player mythology are projections of the substrate rather than independent content generators.

The first implementation proof is the household → property → production → contract → institution → resource shock → consequence → history loop.
