# Data credits

## world_elevation.png

Source: [World elevation map](https://commons.wikimedia.org/wiki/File:World_elevation_map.png)
via Wikimedia Commons, downsampled from the original 21,600×10,800 to
3,840×1,920.

Combines NASA's Blue Marble topography and bathymetry data, originally
created by Jesse Allen at NASA's Earth Observatory using GEBCO (General
Bathymetric Chart of the Oceans) data. Equirectangular projection.

License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
Attribution: Wikimedia Commons user Avsa, NASA Earth Observatory, GEBCO.

Encoding: single-channel grayscale, linear elevation from -8000m (0.0) to
+6400m (1.0). Sea level (0m) sits at approximately 0.5556.
