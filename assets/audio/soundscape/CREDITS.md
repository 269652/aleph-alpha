## Note on `rainforest_day.wav`

Kept as the original uncompressed WAV (24.3 MB) rather than re-encoded to
`.ogg` — no audio re-encoding tool (`ffmpeg`) was available in the
environment this was fetched from. Re-encoding to Ogg Vorbis at a
reasonable bitrate would cut this to roughly 2-3 MB with no audible loss
for an ambient loop; worth doing opportunistically if a session with
`ffmpeg` available touches this file again.
